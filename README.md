## 🚀 What I'm working on

### [Opotunity](https://www.opotunity.ro) · Co-Founder & Software Engineer
A live SaaS platform connecting students and junior professionals with volunteering opportunities.
- Skill-based opportunity matching, end-to-end application workflows and admin dashboards for organizations
- REST APIs, authentication and core business logic built with Node.js, Prisma and MySQL
- API integration that automatically syncs opportunities from a partner organization's website
- Backend deployed and maintained on AWS EC2
- Partnerships with 4 organizations, including Habitat for Humanity Romania
